
# MiniBank - Java OOP Project

**Student ID:** 25AIML077

## About the Project
MiniBank is a console-based banking application developed using Java.
This project is being built throughout the semester as part of the
CEUE203 Object-Oriented Programming practicals.

## Practical 1
The first practical includes:
- Bank name and branch information using a record
- Menu options using an enum
- Menu selection using a switch expression
- User input using Scanner
- Repeating menu until the user exits

## Technologies Used
- Java JDK 17+
- Visual Studio Code
- GitHub

## How to Run
Compile the program:

    javac MiniBank.java

Run the program:

    java MiniBank

## Future Development
More banking features will be added in upcoming practicals.
